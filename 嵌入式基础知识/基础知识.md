# TCP/IP
* 应用层：用户接触交互使用的部分，例如http，tfp（文件传输），dns（域名解析）等
* 传输层：传输应用层数据的，例如tcp，udp
* 网络层：处理网络中的数据包，例如IP协议，arp协议
* 数据链路层：连接硬件的部分，如控制网卡，硬件相关的设备驱动
* 物理层：负责传输数据的硬件部分，例如光纤，无线

# 内存分区：
* 堆：存放new或者malloc对象
* 栈：存放局部变量

* 全局存储区：存放全局变量和静态变量
* 常量存储区：存放二进制代码片段

```C语言
char *a;                // 栈
a = (char*)malloc(10);  // 分配的10字节空间在堆里
static int b;           // 全局存储区
extern char c;     // 全局存储区
strcpy(c, "123");  // 常量区
```

# FREERTOS
* 任务优先级：数字越大，优先级越高，内核花销的内存空间越多
* 栈大小，是bit，不是Bytes
* RT-thread

# 系统中断优先级：数字越小，优先级越高

# pack字节对齐使用
优点
1：节省空间，在结构体里有不同的数据类型，编译器会使用默认对齐，对不足的数据进行填充，造成浪费
2：某些场景必须使用字节对齐，比如网络通信，文件格式等
缺点：
1：访问速度变慢，比如使用1字节对齐，那非1字节数据需要多次访问，导致访问速度变慢

# IIC 和 spi usart的区别
spi:
全双工，4根线 MOSI主出从入 MISO主入从出 SCKL时钟 CS/SS片选
速度达到几十Mbps，传输距离较短
一对多，但是每多一个从设备，就需要多一个cs引脚，布线麻烦

iic:
半双工，两根线SDA SCL
速度几k或者几M
多主多从，布线简单，

usart
全双工，4根线，RX TX GND SCLK（同步模式才用）异步不需要CLK
点对点发送，支持长距离通信
需要起始位和停止位以及设置相同的波特率
默认空闲是上升沿，当检测到下降沿证明数据开始传输，每0.5个bit采样一次，然后8个bit采一次停止位

# Queue 先进先出
先进先出，操作简单
但是只能从队头插入，队尾删除
不能随机访问

# usart
* 全双工
* 协议：数据位，校验位，波特率，停止位等等
